# Security Policy

WorldCut is experimental and is not a standalone security boundary. Do not use
it as the sole authorization control for production side effects.

## Reporting a vulnerability

Please report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/Jason-Doyle/WorldCut/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability.

Include a minimal reproduction, affected version, expected behavior, and
potential impact. Reports will be acknowledged as soon as practical.

## Supported versions

Only the latest revision of the `main` branch is currently supported.
