# Support

## Before opening an issue

1. Read the [README](README.md), [production guide](docs/PRODUCTION.md), and
   [integration guide](docs/INTEGRATIONS.md).
2. Confirm the behavior with the latest release.
3. Run `npm run check` and the smallest relevant example.
4. Remove tokens, private repository data, and sensitive provider responses.

## Bug reports

Include:

- WorldCut version or commit;
- Node.js version and operating system;
- the smallest safe verification input;
- expected and observed verdicts;
- relevant error code.

## Security

Do not open a public issue for a vulnerability. Follow
[SECURITY.md](SECURITY.md).

## Support level

WorldCut is maintained on a best-effort basis and does not include a commercial
support commitment.
